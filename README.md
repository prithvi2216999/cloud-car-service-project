# Vehicle Service Management System

Cloud-based vehicle service tracking web application built using Streamlit, Python, MySQL, and AWS EC2.

## Features
- Register vehicle service requests
- Track vehicle service status
- View past service records
- Admin dashboard for managing services
- Cloud deployment using AWS EC2

## Technologies Used
- Python
- Streamlit
- MySQL
- Pandas
- AWS EC2
- GitHub
